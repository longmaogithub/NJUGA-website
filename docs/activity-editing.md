# 活动模块编辑

后台「活动」保留标题、活动日期、状态、封面和简介等基本信息，下方正文区域分为四部分：

- 正文：景区介绍等自由图文，网页不额外显示「正文」或「景区介绍」副标题。
- 行程安排：起始时间（北京时间，精确到分钟）、集合地点、解散地点、活动路线、结束时间说明。起始时间包含日期；活动日期用于列表排序，请保持两者日期一致。
- 注意事项：支持段落、编号列表和文字格式。
- 组织人员：可新增多行，自定义分工（如策划、文字、海报、摄影）及人员姓名。

这四部分及其子字段全部非必填。未填写的字段不显示，整个模块为空时也不显示模块标题；只有人员或只有分工的条目仍可保存。网站自动生成的模块与字段副标题不使用 emoji。

栖霞山活动已从原正文迁入这些字段，保留原有景区介绍、七条报名须知、路线和全部署名。原文未单列解散地点，因此该字段留空。其他旧活动仍按原正文显示；若逐步拆分旧活动，请将已移入模块的文字从正文中移除，避免重复。

文章和独立页面的正文规则不变。活动页仍沿用现有紫色主题、正文宽度、字体和段落布局。
