# 管理文章栏目

1. 进入后台「网站设置」→「文章栏目」。
2. 在栏目列表中新增一项，填写名称；名称不能重复，不能使用系统保留的「全部」。
3. 拖动列表项调整顺序，保存。网站分类按钮按此顺序展示，「全部」固定排第一。
4. 编辑或新建文章，在「栏目」中选择刚添加的栏目。若另一窗口尚未更新，先保存当前草稿，再刷新后台。

栏目名称和文章内容均保存到 GitHub；自动发布完成后官网更新。初始顺序仍为九州风物、地图上、招新、其他。尚无文章的新栏目也会显示，点击时显示无匹配文章的提示。

重命名或删除栏目不会自动批量改写旧文章。请先把旧栏目下的文章逐篇改选目标栏目，再删除旧名称。若仍有已发布文章使用旧名称，网站会将该栏目保留在末尾，避免文章失去分类入口；全部迁移后旧栏目自动消失。
